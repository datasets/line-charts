# Measurements

Reproducible render-time and bundle-size records for the site, never deployed (see `.assetsignore`). `npm install` here, then `node timings.mjs` (serves the repo root in-process, opens each `demos/<lib>.html?chart=<key>&bare=1` in system Chrome at 900×700, DPR 1, seven runs per cell with the first reported as cold, and reads each page's own render badge; `--dpr 2`, `--runs N`, `--headless`, `--only d3,uplot` adjust it) and `node bundles.mjs` (loads each demo page in a fresh context and records every file fetched from jsDelivr, with raw, gzip -9 and as-sent sizes). Both write a dated `.json` and `.md` to `docs/measurements/`, along with the browser, GPU and machine they ran on.
